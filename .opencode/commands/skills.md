Muat dan patuhi aturan proyek JPay di `SKILLS.md` sebelum mengerjakan apa pun.

Langkah:
1. Baca `SKILLS.md` di root proyek.
2. Muat skill `jpay-hackathon` lewat tool `skill` (isinya aturan utama proyek ini).
3. Muat skill `monskill` untuk routing skill MONSKILLS.
4. Pilih dan muat HANYA skill yang relevan dengan task saat ini (mis. `scaffold`, `wallet-integration`, `gas`, `addresses`, `concepts`).
5. Ringkas aturan yang akan dipatuhi dalam maksimal 5 poin, lalu kerjakan task sesuai alur di `SKILLS.md`.

Patuhi stack wajib: Next.js 14 App Router + TypeScript + Tailwind, Privy, wagmi v2 + viem, Monad Testnet, warna utama `#6E54FF`. Fokus MVP yang bisa demo, jangan over-engineer.
